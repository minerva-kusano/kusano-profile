# このサイトのつくり

公開されるページ（`index.html` や `books/` など）は、この `_src/` の中身から生成している。
**生成された HTML を直接書き換えない。** 原稿を直して生成し直す。

```
_src/
  content/     本文の断片（HTML）。原稿はここ。一字単位で著者のもの。
  data/books.json  書誌・書影・販売リンク・各見出しの文字列
  assets/      共通のスタイル（site.css）・スクリプト（site.js）・画像（img/）
  build.py     生成スクリプト
  verify.py    旧・単一ページとの照合（本文・表・図・リンク）
  extract.py   2026年11月に旧ページから原稿を切り出したときの記録（再実行しない）
  legacy/      旧・単一ページの控え
```

## 生成

```
python3 _src/build.py next   # next/ に仮置き版（検索に載らない指定つき）
python3 _src/build.py .      # リポジトリ直下に本番版
python3 _src/verify.py next  # 照合
```

`_` で始まるフォルダは GitHub Pages では公開されない。

## 原稿を扱うときの決まり

- 本文（`content/`）は著者の文章。短くしない、言い換えない、文体や語彙を揃えない、注や書評を省かない。
  変更が要るときは案を示して著者の了解を得る。
- 新しく足す枠の文言（ナビ、ラベル、ページの説明文など）は `build.py` の `NEW` に集めてある。本文と混ぜない。
- 書籍の「編集ノート」は任意。書ける本にだけ置く。編集上の判断やエピソードを創作しない。
- 画像を生成して実績として載せない。空の枠を公開しない。
- 制度についての記述に疑義があっても直さず、確認事項として著者に挙げる。
- 「←New！」の印は著者の指示で付け外しする。
- 計測（GA4）のイベント名 `contact_click` と引数は変えない。
- トップページの `#works` `#editing-philosophy` `#history` `#interests` `#writing` `#fragments` は残す。
- 公開の前に画面を著者に見せ、了解を得てから反映する。

## 書体の決まり

随想・編集後記・「牟言芻鳴」の文章は明朝（`.prose.mincho`）、入口・実務の文章・資料はゴシック（`.prose`）。
長文は1行およそ40字、15px以上。
